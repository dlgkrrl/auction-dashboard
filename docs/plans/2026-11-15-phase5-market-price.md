## 2. 목표

1. 시세를 **코드로** 계산(같은 입력 → 같은 값), 근거(표본 수·범위·기준)를 함께 저장
2. 시세 있는 진행중 물건 41% → **80% 이상**
3. ROI 전세가·월세를 실제 전월세 거래로, 매도가는 비관/기본/낙관 3가지
4. 시세가 채워진 뒤 GAP 점수(4단계 V4 방식) 다시 계산

## 3. 작업

### 5-1 · 시세 계산 코드 (n8n, 크롤러 수정 없음)
- `real_trade_history` 텍스트 → 행 파싱(계약일, 구분, 단지명, 층, 전용면적, 금액/보증금·월세)
- 비교 거래 선택: 같은 단지 + 전용면적 ±10% → 최근 3·6·12개월 순으로 표본 3건 이상인 가장 짧은 기간
- 값: 중앙값(평균 대신, 특이 거래 영향 줄임), P25~P75, 표본 수, 기간, 기준 설명
- 층 보정: 저층(1~2층) −3%, 그 외 0 (표본으로 검증 후 조정)
- 전월세: 같은 기준으로 전세 보증금 중앙값, 월세(보증금·월세) 중앙값
- 새 필드(물건 테이블): `market_price`, `market_price_p25`, `market_price_p75`, `market_sample_count`, `market_basis`, `market_period`, `market_price_date`, `jeonse_median`, `rent_deposit_median`, `rent_monthly_median`
- 기존 `real_trade_3m/6m/12m_avg`는 호환용으로 같은 계산값으로 채움(Dify 값 덮어씀)
- 010 'Dify 결과 파싱' 뒤에 Code 노드 하나 추가, 백필은 1회용 워크플로우(050처럼)

### 5-2 · 실거래 다시 받기 (백필)
- 진행중 물건 중 `real_trade_history`가 빈 물건: 크롤러에 **실거래만 받는 엔드포인트**(`/real-trade?uid=`) 추가 → 1회용 워크플로우가 호출해 채움
- 빈 이유를 용도별로 기록(아파트인데 비었는지, 빌라라 원래 없는지)

### 5-3 · 국토부 실거래가 API (빈 물건 보완)
- 공공데이터포털 '국토교통부 아파트/연립다세대/단독다가구 매매·전월세 실거래가' (무료, 키 필요)
- 빌라·단독: 같은 읍면동 + 건축년도 ±5년 + 면적 ±15%의 ㎡당 가격 중앙값 × 전용면적, `market_basis='읍면동 ㎡당'`
- 5-1·5-2로 80%에 못 미칠 때만 진행

### 5-4 · ROI·매도가
- 전세가 = `jeonse_median`(없으면 지금처럼 매도가 × 65%와 '추정' 표시)
- 매도가 기본 = `market_price`, 24개월 뒤 비관/기본/낙관 = 연 −3/0/+3%
- 대시보드 ROI 시뮬레이터·상세 창에 시세 근거(표본 수·기간·범위) 표시

### 5-5 · GAP 재계산
- 050 재실행으로 진행중 물건 GAP 갱신, 등급 분포 비교
