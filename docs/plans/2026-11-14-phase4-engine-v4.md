# 4단계 · 입찰가 엔진 V4

2026-11-14 · 상위 계획: `2026-11-12-auction-improvement-plan.md` 4장 4단계 · 전제: 3단계 통계(`auction_stats`, n8n 049)

## 1. 방식

- **최저가 대비 배수**를 추정한다: 배수 = 낙찰가 ÷ 그 회차 최저가. 법원별 저감률(20%·30%)이나 회차 차이를 흡수하고, 최저가는 입찰 시점에 확정된 값이라 감정가율을 직접 맞히는 것보다 안정적.
- **계층 축소 추정**: 전체 → 법원 → 시군구 → 읍면동 → 단지 순으로 내려가며
  `추정(단계) = (n·중앙값(단계) + K·추정(위 단계)) / (n + K)`, K = 10. 유찰 구간(0·1·2·3·4+)별로 계산, 구간 표본이 없으면 그 단계 전 구간 값.
- 추천가: 목표 = 최저가 × 배수 중앙값(낙찰 확률 약 50%), 상한 = 75% 분위(약 65%), 하한 = 25% 분위. 모두 최저가 이상.
- 신뢰도: 그 유찰 구간에서 표본 5건 이상인 가장 좁은 단계가 단지·읍면동이면 높음, 시군구·법원이면 보통, 아니면 낮음.
- **인수금액은 빼지 않음**: 추천가는 시장 낙찰가 추정치. 인수 부담은 문구로 경고하고 대시보드 수익 계산에서 반영(1단계).
- 통계를 못 찾으면(통계 테이블 비어 있음 등) 기존 V3 표 기반으로 계산.
- 코드: `ops/phase4/engine_v4.js`(공용 추정기), `run_engine_v4.js`(추천가·GAP SCORE·문구), n8n용 `010_engine_v4.js`·`012_result_parse_v4.js`, 백테스트 `backtest.js`.
