## 4. 구조 진단 (리뉴얼이 필요한 이유)
- **파일 하나에 모든 것**: `index.html` 약 250KB(화면·스타일·계산 엔진·차트 전부). 고칠 때 영향 범위를 알기 어려움
- **인라인 스타일 344곳, `font-size` 직접 지정 154곳, 색 코드 37가지**: 같은 '작은 회색 글자'가 곳마다 다른 크기·색 → 이번 줄바꿈 문제의 뿌리. 버튼 모양도 5가지 이상
- **화면 순서가 '일 순서'와 다름**: 지금 위에서부터 숫자 카드 → 관심 물건 → 온도계 → 기회 매트릭스·낙찰가율 차트 → 성적표 → 필터 → 카드. 매일 쓰는 건 '관심 물건 → 새 물건 카드'인데 그 사이에 분석 화면 4개가 끼어 있음
- **물건 카드 정보가 과밀**: 카드 하나에 뱃지 4개 · 가격 2개 · 현금 3줄 · 추천가 · 서류 칩 5개 · 실거래 줄 · 버튼 4개. 휴대폰에서 카드 하나가 화면 하나
- **숫자 표기가 섞임**: '1억 2,200만' / '12,200만' / '122000000원' 혼용, 이모지 라벨이 많아 줄 길이가 늘어남
- **상세 창 휴대폰 아래 버튼이 3줄**: 버튼 6개가 줄바꿈되어 화면 1/4 차지
