## 1. 목표

예측(3·4단계)에 쓸 **깨끗하고 충분한 결과 표본**을 만든다.

1. 결과 테이블을 "매각기일 1회 = 1행" 이벤트 테이블로: 낙찰뿐 아니라 **유찰·변경·불허가·미납**도 기록 → "이 가격엔 아무도 안 썼다"를 확률 추정에 사용
2. 기존 291행 보정 (법원·물건번호·용도·당시 최저가·유찰횟수, 지분/이상치 표시)
3. **표본 확대**: 우리 필터(최저가 2억 이하, 일 30건)와 무관하게 같은 법원의 주거용 매각결과 전체를 매일 가볍게 수집

## 2. 표본 확대 실현 가능성 (확인 완료)

- 마이옥션 종합검색(`/auction/search.php` → `search_list.php`)에 **현재상태(`aresult`)** 필터가 있음: `매각(낙찰)`, `유찰`, `변경`, `불허가`, `미납`, `취하/…` 등 16종 + **매각기일 범위**(`ipdate1/ipdate2`) + 지역·용도·가격 필터.
  → "어제(또는 지난 N일) 창원·김해·양산·함안 등 주거용, 가격 제한 없음, 상태=매각"을 한 번에 조회 가능.
- 목록 행에서 읽는 값(기존 크롤러 코드): 상세번호(uid)·사건번호·주소(시군구)·용도·감정가·최저가. **낙찰가·응찰자 수**는 상세페이지 `#success_man`, 회차별 최저가·유찰 수는 `#plan_sale`에서 읽음(트래커가 이미 파싱 중).
- 확인 못 한 것: 매각 상태 목록 화면에 낙찰가가 바로 나오는지(로그인 필요). → 구현 첫 단계에서 1회 탐색. 나오면 상세 방문을 생략해 더 가볍게.
- 부하 추정: 서류·PDF·AI 분석 없이 목록 1~3쪽 + 상세 HTML만. 물건당 2~3초. 하루 매각 30~60건 가정 시 2~3분 + 유찰 이벤트 포함 시 5분 내외. 기존 01:00 결과추적(25~45분)과 겹치지 않게 **04:30**에 실행 제안.
- 예상 표본 속도: 현재 하루 평균 매각 결과 ~5~10건(우리 물건만) → 확대 후 **하루 30~60건**. 300건 도달(6단계 ML 조건)이 몇 달 → **1~2주**로 단축 예상.

## 3. 설계

### 3-1. 결과 테이블(auction_results) 컬럼

이미 있음: case_no, complex_name, dong, area_m2, floor, appraisal_price, loss_count, actual_bid_price, actual_bid_rate, bidder_count, bid_date, our_bid_target, engine_error_rate, engine_version, fetched_at, real_trade_3m/6m_avg, bid_vs_trade_gap_*, gap_score, (0단계 추가) court, item_no, location, usage, result_type, min_price

2단계 추가:

| 컬럼 | 형식 | 설명 |
|---|---|---|
| detail_uid | 텍스트 | 마이옥션 상세번호. **중복 방지 키** = detail_uid + bid_date |
| sgg | 텍스트 | 시군구 (창원시 성산구, 양산시 …) |
| emd | 텍스트 | 읍면동 |
| min_price_rate | 숫자 | 당시 최저가 / 감정가 (%) |
| sale_round | 숫자 | 회차 (기일표 순번) |
| source | 텍스트 | `tracked`(우리 물건) / `court_list`(표본 확대) |
| item_ref | 숫자 | 우리 물건 테이블 Id (tracked일 때) |
| ai_risk, tenant_count, inherited_amount | 텍스트/숫자 | tracked일 때만 (표본 확대분은 서류 분석 안 함) |
| is_share, is_bulk, is_outlier | 체크 | 통계 제외 표시 (이상치 = 낙찰가율 5% 미만·200% 초과 또는 최저가>감정가) |
| market_price, market_price_date | 숫자/날짜 | 그 시점 시세(실거래 3개월 평균 등). 5단계 전까지는 tracked만 |

`result_type` 값: `매각` / `유찰` / `변경` / `매각불허가` / `대금미납` / `취하` / `기각` / `정지`
